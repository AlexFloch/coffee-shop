# Volta Coffee — сайт кофейни

Адаптивный лендинг вымышленной кофейни. Учебный проект: заказ работает как демо и никуда не отправляется.

**Демо:** [coffee-shop-five-olive.vercel.app](https://coffee-shop-five-olive.vercel.app/)

## Что на странице

- Рассказ о кофе
- Меню
- Адрес и расположение кофейни
- Интерфейс заказа (демо)

## Технологии

- React 18
- Vite
- Tailwind CSS
- Framer Motion (анимации)
- Lucide React (иконки)

## Запуск локально

```bash
git clone https://github.com/AlexFloch/coffee-shop.git
cd coffee-shop
npm install
npm run dev
```

Сайт откроется по адресу, который покажет терминал (обычно `http://localhost:5173`).

## Что я отрабатывал

Адаптивную вёрстку, компонентную структуру на React, анимации на Framer Motion, работу с Tailwind CSS.
